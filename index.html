Vulnerability 2: Cross-Site Scripting (XSS)

This form accepts user input without proper sanitization.

XSS Payload Example (for testing):
Try entering: <img src=x onerror=alert('XSS')>
This demonstrates how malicious scripts execute in user browsers.

How to Prevent These Issues

  • Credentials: Never store secrets in client-side code. Use environment variables, server-side configuration, or secure secret management systems.
  • XSS: Sanitize and encode all user inputs. Use Content Security Policy headers. Implement output encoding. Validate inputs server-side.
